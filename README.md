# 💰 Учёт расходов

Многопользовательское веб-приложение для контроля личного бюджета. Каждый пользователь видит только свои траты и категории.

## 🛠 Стек
Next.js (App Router), TypeScript, Tailwind CSS, SQLite, Prisma 7, bcryptjs, Zod.

## 🚀 Как запустить
```bash
npm install
npx prisma migrate dev
npm run db:seed
npm run dev

Открыть: http://localhost:3000

✨ Что умеет
Регистрация и вход (cookie-сессии).
Добавление, редактирование и удаление расходов.
Фильтрация по категориям и датам.
Управление категориями.
Изоляция данных.

 ## 📁Структура проекта
- `app/api/` — REST API (регистрация, вход, расходы, категории).
- `app/dashboard/` — главная страница со списком трат.
- `app/expenses/` — добавление и редактирование расходов.
- `prisma/` — схема БД, миграции и seed-скрипт.
- `lib/` — утилиты (Prisma Client, аутентификация, схемы Zod).
- `components/` — переиспользуемые UI-компоненты.

## 🔒Безопасность
- Пароли хранятся в виде хеша (`bcryptjs`).
- Сессии реализованы через `cookie`.
- **Изоляция данных:** каждый запрос к базе данных фильтруется по `userId` текущего пользователя. Чужие записи недоступны даже при прямом обращении по ID.

## 📄 Лицензия
Учебный проект, созданный в рамках практики.
